# Search filter

This component is a reusable filter component. It's a wrapper component around the [vl-ui-search-filter component](https://overheid.vlaanderen.be/webuniversum/v3/documentation/components/vl-ui-search-filter) from the Webuniversum of the Flemish Government.

## How to use

```js
<template>
    <search-filter
        :filters="[]"
        @updateFilter="function"
    />
</template>
```
