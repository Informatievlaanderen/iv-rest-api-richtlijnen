# Typography

This component is a reusable info tile. It's a wrapper around the [vl-ui-typography](https://overheid.vlaanderen.be/webuniversum/v3/documentation/atoms/vl-ui-typography)from the Webuniversum of the Flemish Government.

## How to use

```vue
<template>
  <typography>
    <h1>Hello world</h1>
  </typography>
</template>
```
